TrainingRecord 界面设计 v1

方向 B「健身」式：深色优先、圆体数字，最佳 1RM 和容量各有固定颜色。只用 iOS 系统控件，规范见 ui/DESIGN.md。待人类批准。

最佳 1RM 容量 可点击 错误 / 删除

记录

一次训练 = 日期 + 若干动作，每个动作下逐组记重量和次数。「保存」在右上角，能保存时才亮起；保存成功后表单清空，底部弹出提示并伴随触感。

历史

顶部是本周汇总（训练次数、容量、哪几天练过），下面按月分组列出每次训练。容量数字始终是青色。左滑删除。

训练明细

从历史行点进来。每个动作标出最佳估算 1RM（玫红），每组右侧是该组的估算 1RM，最佳的那组同色。

趋势

变更：从「历史」页工具栏里的分段切换，提为独立的第三个标签。先选动作，再在「最佳 1RM / 容量」之间切换；图表颜色跟随指标。纵轴不从 0 起，图下列出每次数值。

每个交互组件的全部状态。iOS 无鼠标悬停，hover 指 iPad 指针；focus 指外接键盘的焦点环。本页的按钮和输入框也是真的，可以直接点、按 Tab 试。
